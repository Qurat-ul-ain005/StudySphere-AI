# StudySphere AI

## One Platform. Multiple AI Learning Assistants.

StudySphere AI is a full-stack AI learning platform that helps students study using multiple specialized AI agents.

## Features

- User Authentication
- Document Upload
- AI Summarization
- AI Explanation
- AI Quiz Generation
- AI Flashcards
- AI Study Planner
- AI Question Answering (RAG)
- Personalized Recommendations

## Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- FastAPI

### Database
- SQLite

### AI
- Gemini API
- LangChain
- ChromaDB
- Sentence Transformers
- Scikit-learn
